# PyBERT 信号链配置工具

直接用浏览器打开 `index.html`。页面不需要安装依赖、启动后端或连接网络；源码链接需联网打开。

- “设置”是默认页面：调制采用 NRZ / PAM-4 / Duo-binary 单选项，枚举采用下拉框，数值采用带单位的输入框，Boolean 采用开关。发射电压使用源码名称 **Vod**，默认 1 V；本模型没有独立的供电 Vdd 设置。
- 点击链路图或左侧模块可切换设置；搜索字段或中文说明可直接定位到对应控件。只有参考信息的条目会定位到“参数说明”。
- “按原 GUI 查找设置”按桌面分组列出控件，可直接跳转到当前 WebUI 的对应位置，并区分草稿与未接入项目。
- Native Tx/Rx FFE 和 DFE 提供完整 tap 表；Rx FFE 显示全部 100 个槽位，Ntaps 更新启用状态。DFE 可逐行编辑或全部启停；引擎只使用首个禁用 tap 之前的连续前缀。
- CTLE、CDR、通道来源、封装预设、AMI 调用方式等会联动相关控件。未满足条件的控件会禁用并说明原因。
- 修改自动保存在当前浏览器的本地草稿中，切换模块和刷新页面后可恢复。错误输入也保留并标记；恢复当前模块或全部默认值后可撤销，继续编辑会结束这次撤销机会。
- “参数说明”保留默认值、范围、生效条件、API/内部/输出标记及源码链接。“实现映射”解释代码中的实际位置、替代关系和已知限制。

## 草稿边界

此页面不加载模型、不运行计算，也不写入 PyBERT 配置文件。Tx/Rx 方案同步影响草稿与链路图，但不表示 AMI 模型已通过解析或能力验证。切换 AMI 时保留暂不使用的 Native 参数；实际 PyBERT 模式切换回调另有行为。

文件选择只记录文件名，不读取或上传内容；可手工填写路径，多文件列表按行编辑顺序。模型解析状态和操作入口在设置页显示为未提供/禁用；Model_Specific 示例保留在参考页。

Rx FFE 权重按数组索引保存；修改 Npre 只预览 tap 位置标签，不执行 PyBERT 的 tap 移位回调。无显式范围的 Float 字段只检查数字格式，不能把本页面的草稿校验视为物理可行性或可运行性验证。

本地存储使用 `pybert-chain-draft-v1`，与当前源码快照绑定。存储被浏览器禁用时，界面会显示“仅当前页面保留”。不同浏览器、文件 URL 和 HTTP 地址可能使用不同的存储空间。

依据：PyBERT 11.1.0，commit `1bc905d577d2f3bd9471421cfbf3d422d4e6080e`（2026-10-23 研究快照）。目录与源程序独立，源码升级后需要重新核对映射。初始值不代表运行后的自适应结果，也不代表已加载 AMI 模型的配置。

主链按 `Source → Tx EQ → Channel → Noise → Rx CTLE → Rx FFE → DFE / Slicer` 展示；Noise 是加法注入，CDR/AGC 是判决控制，Observe 是多节点分析，器件模型并入 Channel。Rx AMI Init 会改变显式噪声注入位置；Tx GetWave 噪声路径、双 GetWave clocks、CTLE 文件导入等实现限制在对应模块中保留说明。

文件分工：`catalog.js` 保存参数说明与源码映射；`settings.js` 定义字段类型、默认草稿、条件与输入校验；`gui-map.js` 保存原 GUI 控件清单；`app.js` 处理渲染、编辑和本地保存；`styles.css` 定义响应式布局。完整分析见上一级 `pybert-signal-chain-and-parameters.zh-CN.md`。
