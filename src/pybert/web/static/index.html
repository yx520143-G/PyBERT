PyBERT Signal Chain Workbench
Edit a node, Run, then choose Responses, Waveform, Eye or Jitter. Editing marks an older run stale. All plots bind to the selected successful run. Compare all points in one run, or the selected chart across two successful runs. Expand viewer for readable axes and legends. Zoom and switching views reuse saved datasets.
Five observation points include an independent Rx FFE helper analysis. Channel clean eye and GUI-compatible 1mV display noise are separate cached views. Jitter bathtubs are crossing timing estimates, not full voltage margin or BER qualification. CDR spectrum preserves the native legacy log10 ratio without a ×10/20 factor. Missing old-schema analyses and failed fits show their availability.
Native NRZ/PAM-4/Duo-binary、真实 single/ordered cascade、lane/FEXT、Native package 和独立 COM 已接入。COM 使用自己的单 .s4p 与 spreadsheet/明确默认参数，不继承当前 EQ/noise/bitrate。时间文件、启用的 CTLE File、非零 impulse_length 及 package+FEXT 有明确阻塞。Optimization: #8；Viterbi: #9；活动 IBIS-AMI: #10。Rx Cac 当前未消费；RLM 只属于优化。
Abort requests cooperative cancellation; the native worker may finish its current DFE or analysis group before observing it. Closing this page does not cancel a task. Two successful runs are cached temporarily (768 MiB arrays per record); restarting the service clears them. Save a full .pybert_run archive to reopen without original resource files. Four explicitly removable references have a total 1 GiB array budget; overflow is refused without evicting references. Legacy files require trusted local pickle selection and remain index-only diagnostics when axes are missing. Saving selected results uses its original inputs and arrays.
Load 支持受限 Native YAML 和已知容器的 legacy pickle；未知对象拒绝执行。Save/Save As 导出当前草稿，资源 bytes 不附带，YAML 相对引用需显式绑定或本机基目录。runtime_extensions 用版本化注释保留；Native 桌面不会消费该扩展。旧 pickle 保存时转为 YAML。浏览器下载不承诺覆盖原路径。
