PyBERT Signal Chain Workbench
Edit a node, Run, then choose Responses, Waveform, Eye or Jitter. Editing marks an older run stale. All plots bind to the selected successful run. Compare all points in one run, or the selected chart across two successful runs. Expand viewer for readable axes and legends. Zoom and switching views reuse saved datasets.
Five observation points include an independent Rx FFE helper analysis. Channel clean eye and GUI-compatible 1mV display noise are separate cached views. Jitter bathtubs are crossing timing estimates, not full voltage margin or BER qualification. CDR spectrum preserves the native legacy log10 ratio without a ×10/20 factor. Missing old-schema analyses and failed fits show their availability.
Native NRZ/PAM-4 only. Channel files / FEXT / package / COM: #4. Optimization: #8. Viterbi: #9. IBIS-AMI: #10. Unsupported active paths are rejected. Rx Cac is not consumed by the native engine; RLM belongs to optimization.
Abort requests cooperative cancellation; the native worker may finish its current DFE or analysis group before observing it. Closing this page does not cancel a task. Two successful runs are cached temporarily; restarting the service clears them.
Load / Save use native PyBertCfg YAML. Save downloads the current validated input under its logical name; Save As chooses a new name. Browser downloads do not overwrite an original source path.
